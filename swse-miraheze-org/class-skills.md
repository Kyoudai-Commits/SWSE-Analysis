# Class Skills

> Source: [https://swse.miraheze.org/wiki/Class_Skills](https://swse.miraheze.org/wiki/Class_Skills) · Retrieved 2026-10-09T08:06:20Z.

*Reference Book: [Core Rulebook](https://swse.miraheze.org/wiki/Core_Rulebook "Core Rulebook")*

Every class has a list of Class Skills. Once a player selects a [Heroic Class](https://swse.miraheze.org/wiki/Heroic_Class "Heroic Class") for their character, they become [Trained](https://swse.miraheze.org/wiki/Trained "Trained") in a number of [Skills](https://swse.miraheze.org/wiki/Skills "Skills") from the character's list of Class Skills. The exact number of Trained Skills a player can choose at 1st level depends on the character's class:

Put another way, a character's [Trained Skills](https://swse.miraheze.org/wiki/Trained_Skills "Trained Skills") represent a subset of that character's Class Skills. Every time a character picks up a new [Heroic Class](https://swse.miraheze.org/wiki/Heroic_Class "Heroic Class"), their list of Class Skills grows to include those of the new class, but the only way to gain new [Trained Skills](https://swse.miraheze.org/wiki/Trained_Skills "Trained Skills") after 1st level is to take the [Skill Training](https://swse.miraheze.org/wiki/Skill_Training "Skill Training") feat or to increase a character's [Intelligence](https://swse.miraheze.org/wiki/Intelligence "Intelligence"). For example, a [Noble](https://swse.miraheze.org/wiki/Noble "Noble") gets 6 [Trained Skills](https://swse.miraheze.org/wiki/Trained_Skills "Trained Skills") at 1st level. If they have a +1 [Intelligence](https://swse.miraheze.org/wiki/Intelligence "Intelligence") modifier, their total becomes 7 [Trained Skills](https://swse.miraheze.org/wiki/Trained_Skills "Trained Skills"). The [Noble](https://swse.miraheze.org/wiki/Noble "Noble") then selects 7 [Skills](https://swse.miraheze.org/wiki/Skills "Skills") from their list of Class Skills, which then become [Trained Skills](https://swse.miraheze.org/wiki/Trained_Skills "Trained Skills") for them.

[Nonheroic](https://swse.miraheze.org/wiki/Nonheroic "Nonheroic") characters treat all [Skills](https://swse.miraheze.org/wiki/Skills "Skills") except [Use the Force](https://swse.miraheze.org/wiki/Use_the_Force "Use the Force") as Class Skills. The Class Skills of Beast characters include [Acrobatics](https://swse.miraheze.org/wiki/Acrobatics "Acrobatics"), [Climb](https://swse.miraheze.org/wiki/Climb "Climb"), [Endurance](https://swse.miraheze.org/wiki/Endurance "Endurance"), [Initiative](https://swse.miraheze.org/wiki/Initiative "Initiative"), [Jump](https://swse.miraheze.org/wiki/Jump "Jump"), [Perception](https://swse.miraheze.org/wiki/Perception "Perception"), [Stealth](https://swse.miraheze.org/wiki/Stealth "Stealth"), [Survival](https://swse.miraheze.org/wiki/Survival "Survival"), and [Swim](https://swse.miraheze.org/wiki/Swim "Swim").
