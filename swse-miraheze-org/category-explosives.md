# Category : Explosives

> Source: [https://swse.miraheze.org/wiki/Category:Explosives](https://swse.miraheze.org/wiki/Category:Explosives) · Retrieved 2026-10-09T08:04:31Z.

Sometimes a mission calls for the use of more powerful Explosives than either [Grenades](https://swse.miraheze.org/wiki/Grenades "Grenades") or [Thermal Detonators](https://swse.miraheze.org/wiki/Thermal_Detonators "Thermal Detonators"). Set Explosives aren't ranged weapons and can't be used like [Grenades](https://swse.miraheze.org/wiki/Grenades "Grenades"). Placing an Explosive requires a [Mechanics](https://swse.miraheze.org/wiki/Mechanics "Mechanics") check. When set and activated, the charge's Timer begins counting down. Standard Timers can be set with as much as an hour delay. Longer delays require specialized Timers.

With a successful [Mechanics](https://swse.miraheze.org/wiki/Mechanics "Mechanics") check, explosives ignore the [Damage Reduction](https://swse.miraheze.org/wiki/Damage_Reduction "Damage Reduction") of objects to which they're attached. Particularly good [Mechanics](https://swse.miraheze.org/wiki/Mechanics "Mechanics") check results can increase the damage even more. Multiple explosives rigged to explode at the same time deal extra damage: Every time you double the number of Explosives used, you add +2 dice of damage. For example, two blocks of [Detonite](https://swse.miraheze.org/wiki/Detonite "Detonite") deal 7d6 points of damage, while four blocks deal 9d6 points of damage.
