# Initiative (Dex)

> Source: [https://swse.miraheze.org/wiki/Initiative](https://swse.miraheze.org/wiki/Initiative) · Retrieved 2026-10-09T08:06:59Z.

*Reference Book: [Core Rulebook](https://swse.miraheze.org/wiki/Core_Rulebook "Core Rulebook")*

Initiative skill checks are affected by an **[Armor Check Penalty](https://swse.miraheze.org/wiki/Armor_Check_Penalty "Armor Check Penalty")**.

Use this skill to gain an advantage in combat.

**Special:** You can [Take 10](https://swse.miraheze.org/wiki/Take_10 "Take 10") on an Initiative check, but you can't [Take 20](https://swse.miraheze.org/wiki/Take_20 "Take 20").

## Applications

The following are the primary applications of the Initiative skill.

### Start Battle

An Initiative check sets the order of combat when a fight starts. Each character aware of the fight makes an Initiative check to determine the [Initiative Order](https://swse.miraheze.org/wiki/Initiative_Order "Initiative Order"), and goes in order from highest to lowest. When [Piloting](https://swse.miraheze.org/wiki/Piloting "Piloting") a [Vehicle](https://swse.miraheze.org/wiki/Vehicle "Vehicle") in combat, you must apply the Vehicle's size modifier to your Initiative check:

| VEHICLE SIZE | SIZE MODIFIER |
| --- | --- |
| Large | -1 |
| Huge | -2 |
| Gargantuan | -5 |
| Colossal | -10 |
| Colossal (Frigate) | -10 |
| Colossal (Cruiser) | -10 |
| Colossal (Station) | -10 |

### Avoid Feint

When an opponent attempts to [Feint](https://swse.miraheze.org/wiki/Feint "Feint") in combat, you oppose their [Deception](https://swse.miraheze.org/wiki/Deception "Deception") check with an Initiative check. If you meet or beat their [Deception](https://swse.miraheze.org/wiki/Deception "Deception") check result, their [Feint](https://swse.miraheze.org/wiki/Feint "Feint") result fails.
