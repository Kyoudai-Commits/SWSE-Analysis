# Category : Appendages

> Source: [https://swse.miraheze.org/wiki/Category:Appendages](https://swse.miraheze.org/wiki/Category:Appendages) · Retrieved 2026-10-09T08:08:21Z.

The types of Appendages a Droid has determines how well it is able to touch, hold, lift, carry, push, pull, or place objects. A limb that isn't used for Locomotion or balance has one of the following types of Appendages: [Probe](https://swse.miraheze.org/wiki/Probe "Probe"), [Instrument](https://swse.miraheze.org/wiki/Instrument "Instrument"), [Tool Mount](https://swse.miraheze.org/wiki/Tool_Mount "Tool Mount"), [Hand](https://swse.miraheze.org/wiki/Hand "Hand"), or [Claw](https://swse.miraheze.org/wiki/Claw "Claw").

Droids can use their Appendages to make [Unarmed Attacks](https://swse.miraheze.org/wiki/Unarmed_Attacks "Unarmed Attacks"). The damage dealt by an [Unarmed](https://swse.miraheze.org/wiki/Unarmed "Unarmed") attack depends on the Droid's size and the type of Appendage. The table below lists the base [Unarmed](https://swse.miraheze.org/wiki/Unarmed "Unarmed") damage; remember to apply the Droid's [Strength](https://swse.miraheze.org/wiki/Strength "Strength") modifier to this base damage. A Droid can have any number of Appendages, but this does not increase the number of actions or attacks the Droid can make in a round.
