# Basic Processor

> Source: [https://swse.miraheze.org/wiki/Basic_Processor](https://swse.miraheze.org/wiki/Basic_Processor) · Retrieved 2026-10-09T08:08:15Z.

*Reference Book: [Core Rulebook](https://swse.miraheze.org/wiki/Core_Rulebook "Core Rulebook")*

**Cost:** 0

**Weight:** 5 Kilograms

Basic Processors are not designed for creative thought and problem solving, and as such most [Droids](https://swse.miraheze.org/wiki/Droids "Droids") interpret instructions and behavioral inhibitors very literally. Furthermore, Basic Processors are very limited in that the Droid cannot perform any task for which it was not programmed. For example, a Droid that is not [Trained](https://swse.miraheze.org/wiki/Trained "Trained") in the [Deception](https://swse.miraheze.org/wiki/Deception "Deception") skill cannot lie or otherwise convey false or unknown information.

A Droid with Basic Processor cannot use any skill [Untrained](https://swse.miraheze.org/wiki/Untrained "Untrained") except for [Acrobatics](https://swse.miraheze.org/wiki/Acrobatics "Acrobatics"), [Climb](https://swse.miraheze.org/wiki/Climb "Climb"), [Jump](https://swse.miraheze.org/wiki/Jump "Jump"), and [Perception](https://swse.miraheze.org/wiki/Perception "Perception"). Similarly, a Basic Processor does not allow a Droid to use any weapon with which it is not proficient, and a Droid's behavioral inhibitors may prevent it from harming sentient living beings altogether. Every [Droid](https://swse.miraheze.org/wiki/Droid "Droid") comes with a Basic Processor, at the very least.
