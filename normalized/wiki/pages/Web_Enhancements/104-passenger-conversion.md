# Passenger Conversion

**Q:** [[Passenger_Conversion]] says that it creates room for a number of passengers equal to the ship's size modifier.

Wouldn't the size modifier be -10 for ships that big? Or does it refer to some other size modifier (such as the one used for [[Grappling]])?

**A:** It is an error, so consider this to be errata: [[Passenger_Conversion]] has sufficient space for a number of passengers equal to the ship's [[Cost_Modifier]], not size modifier.
