# Multiple Attacks with Multiple Targets

**Q:** Can you use [[Double_Attack]] or [[Triple_Attack]] to attack the same target multiple times in the same round, or do you have to attack different targets?

**A:** The extra attacks from [[Double_Attack]], [[Triple_Attack]], and fighting with multiple weapons can be directed at the same target or at different targets, in any combination and any order that you choose.
