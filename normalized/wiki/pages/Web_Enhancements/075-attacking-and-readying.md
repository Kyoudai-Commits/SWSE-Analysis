# Attacking and Readying

**Q:** Can you make an [[Attack]] ([[Standard_Action]]) and then [[Ready]] a [[Move_Action]] in the same turn? I can't find any rule that says you can't, but older versions of the game wouldn't allow this.

**A:** No, it's not allowed. [[Readying_an_Action]] is itself a [[Standard_Action]] regardless of the type of [[Action]] readied ([[Standard_Action]], [[Move_Action]], or [[Swift_Action]]). This is apparently missing from the text, so it will be added to the errata.
