# Building Lightsabers

**Q:** The [[Jedi]] class table includes "Build Lightsaber" at 7th level. Does this mean that only a [[Jedi]] can build a [[Lightsaber]]?

**A:** No. As noted in [[Lightsaber_Construction]], a [[Lightsaber]] can be built by any character who has at least seven Heroic Levels, has the [[Force_Sensitivity]] Feat, and is proficient with [[Lightsabers]]. The entry in the [[Jedi]] class is just meant to be a reminder of this fact.
