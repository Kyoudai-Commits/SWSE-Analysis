# New Prestige Class Talents

This section presents new [[Talents]] for several of the [[Prestige_Classes]] in the *[[Core_Rulebook]]*. These [[Talents]] are suitable for heroes of any [[Era_of_Play]], but they are especially appropriate for heroes in a [[Rebellion_Era_Campaign]].

- [[Ace_Pilot]]
  - New [[Wingman_Talent_Tree]]
- [[Officer]]
  - New [[Rebel_Recruiter_Talent_Tree]]

The following new [[Prestige_Classes]] are available in [[The_Rebellion_Era]].

| PRESTIGE CLASS | PREREQUISITES |
| --- | --- |
| [[Improviser]] | - **Minimum Level:** 7th - **[[Trained_Skills]]:** [[Mechanics]] and [[Use_Computer]] - **[[Feat]]:** [[Skill_Focus_(Mechanics)]] |
| [[Pathfinder]] | - **Minimum Level:** 7th - **[[Trained_Skills]]:** [[Perception]], [[Survival]] - **[[Talents]]:** Any two from the [[Awareness_Talent_Tree]], [[Camouflage_Talent_Tree]], or [[Survivor_Talent_Tree]] |
