# Category : Explosives

Sometimes a mission calls for the use of more powerful Explosives than either [[Grenades]] or [[Thermal_Detonators]]. Set Explosives aren't ranged weapons and can't be used like [[Grenades]]. Placing an Explosive requires a [[Mechanics]] check. When set and activated, the charge's Timer begins counting down. Standard Timers can be set with as much as an hour delay. Longer delays require specialized Timers.

With a successful [[Mechanics]] check, explosives ignore the [[Damage_Reduction]] of objects to which they're attached. Particularly good [[Mechanics]] check results can increase the damage even more. Multiple explosives rigged to explode at the same time deal extra damage: Every time you double the number of Explosives used, you add +2 dice of damage. For example, two blocks of [[Detonite]] deal 7d6 points of damage, while four blocks deal 9d6 points of damage.
