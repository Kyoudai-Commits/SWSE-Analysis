# Cybernetic Surgery

*Reference Book: [[Core_Rulebook]]*

You can perform the surgical procedures necessary to graft cybernetic components onto living flesh.

**Prerequisite:** [[Trained]] in [[Treat_Injury]]

**Effect:** You can install [[Cybernetic_Prostheses]] on living beings. The surgical procedure takes 1 hour of uninterrupted work, after which you must make a DC 20 [[Treat_Injury]] check. If the check succeeds, the [[Cybernetic_Prosthesis]] is installed correctly. If the check fails, the device is not properly installed; however, you can try again after another uninterrupted hour of [[Surgery]].

**Special:** You can install a [[Cybernetic_Prosthesis]] on yourself, but you take a -5 penalty on the [[Treat_Injury]] skill check. If you have the [[Surgical_Expertise]] feat, you can install a [[Cybernetic_Prosthesis]] in 10 minutes instead of 1 hour.
